# Custom View Mode

Расширение для модификации того, как страницы сайта отображаются на стороне пользователя. Скрывайте ненужные блоки или выбирайте один элемент для автоматической подгонки под окно.

## Установка

1. Откройте `chrome://extensions` в Google Chrome (версия 106 или новее).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение / Load unpacked**.
4. Выберите папку `ReSizer`, в которой находится `manifest.json`.
5. Откройте обычную HTTP/HTTPS-страницу. Расширение также умеет запускаться на вкладках, открытых до установки.

После изменения исходников нажмите кнопку обновления на карточке расширения и перезагрузите открытые страницы.

## Использование

1. Нажмите правую кнопку мыши на странице и выберите **Start View Customization**. Можно также открыть значок расширения и нажать **Настроить страницу**.
2. В правом нижнем углу появится полупрозрачная панель. Перетаскивайте её за заголовок.
3. Выберите действие **Скрывать** или **Подогнать под окно**. Наведите указатель на элемент: рамка покажет выбранный блок. Щёлкните левой кнопкой. Ссылки и кнопки в режиме выбора не выполняют обычные действия.
4. При необходимости включите **Все похожие элементы**: это изменит последнее действие и сразу покажет результат. Если похожих элементов нет, переключатель недоступен.
5. Выберите область действия и нажмите **Принять**. Кнопка **Отклонить** или **Esc** вернёт состояние до текущего сеанса.

**Ctrl+Z** (или **Cmd+Z**) и кнопка **Отменить шаг** возвращают последнее действие целиком. Когда редактируется поле пути раздела, Ctrl+Z отменяет ввод текста обычным способом.

В popup расширения можно временно отключить все правила сайта, удалить только автоподгонку или сбросить все настройки сайта. Отдельно показано количество правил скрытия и автоподгонки. Изменения распространяются на уже открытые вкладки. Сохранение новых правил снова включает сайт. Переход на другой адрес во время настройки отменяет несохранённый сеанс.

## Автоподгонка под окно

1. Запустите настройку и выберите действие **Подогнать под окно**.
2. Щёлкните по нужному элементу. Он останется на странице, а его видимая область увеличится или уменьшится с сохранением пропорций. Масштаб самого Chrome не меняется; основной сценарий — масштаб браузера **100%**.
3. Если картинка находится внутри ссылки `<a><img …></a>`, после выбора картинки нажмите **Выбрать родителя**, чтобы сохранить правило для `<a>`. Подпись и рамка показывают цель. Кнопка **Вернуться к дочернему** возвращает предыдущую цель в этой цепочке.
4. Выберите страницу, раздел или весь сайт и нажмите **Принять**. Можно сохранять только подгонку, без скрытия элементов.

Сохраняется селектор блока, а не фиксированный процент. Если в том же `<a>` появится другая картинка, размер будет пересчитан. Подгонка реагирует на загрузку изображений, изменение содержимого, замену DOM-узла и размеры окна. Для неё доступны ширина родительского контейнера и размер окна с запасом 16 px по его краям; обрезающие предки дополнительно ограничивают доступную область.

Подгоняется внешняя область блока. Его собственная прокрутка и обрезка содержимого сохраняются: содержимое внутреннего скроллера не раскрывается целиком. Элемент не копируется и не переносится в другой контейнер. В начале применения страница и прокручиваемые предки прокручиваются к цели. Дальнейшие пересчёты не возвращают пользователя к элементу после самостоятельной прокрутки.

На странице действует одна автоподгонка. Новый выбор в сеансе заменяет её цель; **Ctrl+Z** восстанавливает предыдущий шаг, включая прокрутку. **Отклонить** восстанавливает прежние правила, оформление и положение прокрутки. При сохранении в той же области цель подгонки заменяется, а скрытия сохраняются. Сохранение только скрытий не удаляет ранее настроенную подгонку.

Если правило совпало с несколькими элементами, подгонка приостанавливается, а панель показывает предупреждение: выберите более точный блок. Если цель ещё не появилась или не имеет размеров, расширение ожидает её. Скрытые блоки и блоки внутри скрытых предков не подгоняются.

## Области действия

| Область | Что входит |
| --- | --- |
| Текущая страница | Точный протокол, хост, порт, путь и query-параметры. Фрагмент `#…` не учитывается. |
| Раздел сайта | Указанный путь и вложенные пути того же сайта. `/articles` охватывает `/articles/42`, но не `/articles-old`. Query-параметры не учитываются. |
| Весь сайт | Все пути текущего `origin` (протокол, хост и порт). Поддомены и HTTP/HTTPS настраиваются отдельно. |

По умолчанию выбран весь сайт. Для раздела предлагается родительский путь; его можно изменить, но текущая страница должна входить в этот раздел. Для одноуровневого адреса `/articles` предлагается `/articles`. На главной странице вариант раздела недоступен. Все подходящие правила скрытия складываются. Для автоподгонки действует приоритет: **точная страница → наиболее глубокий раздел → весь сайт**. Если цель более приоритетного правила отсутствует, расширение ожидает её, не переключаясь на другое правило.

## Как работает скрытие

Расширение хранит CSS-селекторы, а не копию страницы. Приоритет отдаётся устойчивым идентификаторам, атрибутам и классам. Если единственный способ отличить элемент — его положение среди соседей, панель показывает предупреждение. Одиночный выбор уникален на текущей странице; на другой странице правило ищет соответствующий элемент по тем же признакам или положению.

Скрытие использует CSS `display: none !important` пользовательского уровня. DOM-узлы сохраняются, свободное место обычно схлопывается. Динамически добавленные элементы тоже подпадают под сохранённые правила. В режиме группового выбора результат и количество совпадений видны до сохранения.

Существенное изменение вёрстки сайта может потребовать повторной настройки. Автоматического распознавания назначения блоков нет. Иногда до загрузки локальных правил элементы могут кратко появиться на экране.

## Данные, разрешения и ограничения

- Все правила находятся в `chrome.storage.local`. Серверов, аналитики, учётных записей и синхронизации нет. Удаление расширения удаляет его данные.
- Формат хранилища обновлён до версии 2. Прежние правила скрытия версии 1 автоматически переносятся с сохранением областей, идентификаторов и состояния включения сайтов.
- Доступ к HTTP/HTTPS-сайтам нужен для автоматического применения правил при следующих посещениях. `contextMenus` добавляет команду, `scripting` применяет CSS, `storage` хранит правила, `webNavigation` отслеживает SPA-переходы.
- Первая версия выбирает элементы основного документа. Содержимое iframe и Shadow DOM сайтов не поддерживается. Сам iframe и внешний элемент веб-компонента можно скрыть как блок.
- Служебные страницы Chrome, Chrome Web Store, локальные файлы и встроенный просмотрщик PDF не поддерживаются. Для неподдерживаемой страницы popup показывает сообщение.
- Для hash-маршрутов, например `/#/article/42`, область «Текущая страница» общая: фрагмент адреса игнорируется.
- Лимит одного сеанса — 500 действий; одновременно применяемого набора — 5000 селекторов. Общий объём хранения ограничен квотой Chrome.
- Правила скрывают интерфейс, но не блокируют сетевые запросы сайта.
- Подгонка не убирает фиксированные панели сайта и не гарантирует видимость под их перекрытиями. Доступное место может ограничиваться контейнером с обрезкой. Элементам без собственного блока (`display: contents`) и внутренним элементам SVG нужно выбрать подходящего родителя. Внешний SVG, изображение, HTML-блок или сам iframe могут быть целью подгонки.

## Разработка и проверки

Файлы расширения работают без сборки. `core.js` содержит логику адресов и хранения; `selectors.js` — подбор селекторов; `fit.js` — обратимую подгонку и наблюдение за размерами; `background.js` — привилегированные операции и последовательную запись; `content.js` — выбор и панель; `popup.*` — управление сайтом.

Для тестов нужен Node.js 20+ (это необязательно для установки и ручной проверки расширения):

```powershell
npm test
```

Тесты логики не требуют зависимостей. Для браузерных проверок установите Playwright и его Chromium:

```powershell
npm install
npx playwright install chromium
npm run test:browser
```

Браузерные тесты загружают настоящее распакованное расширение в отдельный временный профиль, запускают локальный HTTP-сервер и проверяют выбор, отмену, группировку, сохранение, SPA, новые DOM-узлы, несколько вкладок, ошибки записи и перезапуск браузера. Профиль пользователя не используется. Снимок интерфейса сохраняется в `test-results/customization.png`.

Если совместимый Chromium уже установлен в другом месте, задайте переменную `CRM_CHROMIUM_PATH` с абсолютным путём к его исполняемому файлу. При использовании готового кеша Playwright можно задать `PLAYWRIGHT_BROWSERS_PATH`.

Ручная приёмка: запуск через настоящее контекстное меню Chrome, перемещение панели, выбор/отмена, сохранение и перезапуск браузера, отключение/сброс в popup, работа на обычной странице после выхода из настройки. Публикация в Chrome Web Store не входит в эту поставку.

### Ручная проверка автоподгонки

Автоматические тесты при добавлении этой возможности не запускались. Проверка выполняется пользователем в Chrome:

| Сценарий | Ожидаемый результат |
| --- | --- |
| Обновить расширение на `chrome://extensions`, перезагрузить вкладку, установить масштаб Chrome 100% | Появляется новый режим; прежние скрытия продолжают действовать. |
| Выбрать большую, маленькую, широкую и высокую картинку | Пропорции сохраняются; большая уменьшается, маленькая увеличивается до доступной области. |
| Выбрать картинку внутри `<a>`, перейти к родителю и обратно | Рамка и подпись соответствуют цели; ссылка не открывается при выборе. |
| Сохранить правило для `<a>`, затем заменить его картинку или дождаться отложенной загрузки | Подгонка пересчитывается по новому содержимому без повторной настройки. |
| Изменить размеры окна | Внешний блок пересчитывается по доступной ширине и высоте. |
| Подогнать блок с текстом, смешанным содержимым, видео или внутренней прокруткой | Содержимое масштабируется вместе с блоком; внутренний скроллер сохраняется. |
| После подгонки прокрутить страницу от цели, затем дождаться обновления содержимого | Расширение пересчитывает размер и не возвращает страницу к цели. |
| Выбрать другую цель, нажать Ctrl+Z, затем «Отклонить» | Восстанавливаются предыдущая цель, исходное оформление и соответствующая прокрутка. |
| Сохранить подгонку, обновить страницу, перейти на похожую страницу или SPA-маршрут | Автоматически применяется подходящее правило. |
| Создать разные цели для сайта, вложенного раздела и точной страницы | Приоритет: страница, самый глубокий раздел, сайт. |
| Заменить выбранный DOM-узел другим с тем же селектором | Новая цель подхватывается автоматически. |
| Создать второе совпадение селектора | Подгонка приостанавливается; в панели отображается предупреждение. |
| Скрыть цель или её родителя, затем отменить скрытие | На скрытом блоке подгонка приостанавливается, после восстановления возобновляется. |
| Отключить сайт или удалить только автоподгонку через popup | Масштабирование снимается во всех открытых вкладках; отдельное удаление подгонки сохраняет скрытия. |
| Закрыть и снова открыть Chrome | Области и цели сохранены; прежние правила скрытия не потеряны. |
